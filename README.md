# Restaurant Billing System

## Project Description

The Restaurant Billing System is a simple Python project used to take customer orders and generate the final restaurant bill.

The program allows the customer to select either In-Dining or Takeaway. The customer can select food items, beverages, and desserts from the menu and enter the required quantity.

After completing the order, the program calculates the subtotal, GST, packing charge, and final bill amount.

## Features

- Accepts customer name
- Provides In-Dining and Takeaway options
- Accepts table number for In-Dining
- Adds packing charge for Takeaway
- Displays Food menu
- Displays Beverages and Desserts menu
- Allows multiple items to be ordered
- Stores items, prices, and quantities in lists
- Calculates subtotal
- Calculates 18% GST
- Calculates final bill amount

## How to Run

1. Install Anaconda.
2. Open Anaconda Navigator.
3. Launch Jupyter Notebook.
4. Create a new Python 3 Notebook.
5. Paste the Restaurant Billing System code into one code cell.
6. Press Shift + Enter to run the program.
7. Enter the customer details.
8. Select In-Dining or Takeaway.
9. Select food, beverages, or desserts.
10. Enter the required quantity.
11. Enter 0 when the order is complete.
12. The final bill will be displayed automatically.

## Billing Calculation

Subtotal = Sum of all ordered items

GST = 18% of Subtotal

Packing Charge = Rs. 50 for Takeaway

Packing Charge = Rs. 0 for In-Dining

Final Total = Subtotal + GST + Packing Charge
